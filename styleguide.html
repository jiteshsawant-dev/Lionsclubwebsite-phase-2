Ruleshow to not reintroduce dead styles
1. Reuse the shared class; never re-implement it. If a button is needed, write class="btn-outline". Do not hand-write padding/border/radius for it in a page-level stylesheet — that produces a lookalike that drifts. (This is exactly what happened to the appeals footer link in campaigns.css: a bespoke pill that survived the redesign because nothing pointed at the shared class.)

2. Never copy CSS out of this guide's <style> block. Those .sg-* rules style the guide's own chrome. Copy the class names from the demos instead.

3. Page-scoped CSS may position and space a component, not restyle it. Layout (grid, margin, alignment) is fine. Colour, border, radius, and typography belong to the shared class.

4. Tokens only. No raw hex outside :root. Use var(--navy), var(--gold), var(--rule).

Background rule: Never use pure white (#fff) as a background. Always use --white (#FCF8EF) in its place — for page backgrounds, cards, panels, form inputs, and any surface that would otherwise be white.
Gold rule: Neither --gold (#FCCB06) nor --gold-deep (#e1b703) pass contrast for text on white. Both are accent/decorative only. For gold-toned text on light backgrounds, use --ink or --navy. Gold colors are for borders, focus rings, and icon strokes — we no longer use gold to highlight em text within headings; em should inherit the surrounding heading color.

Typography

Foundations
Type scale only — color is not fixed here. Every style below takes its color from the section background it sits on; see Backgrounds for the exact eyebrow/heading/body pairing per surface.
Use the token, don't retype the numbers. The serif styles below are available as font: shorthands in :root, so a heading is one declaration and an invented value is visibly off-system:

.foo { font: var(--type-panel-title); color: var(--navy); }

--type-display · --type-section-title · --type-panel-title · --type-lead · --type-quote · --type-label

Two caveats: --type-label does not carry its letter-spacing:0.08em or text-transform:uppercase (the font shorthand cannot), and the shorthand resets any font property you don't name — so set font first, then overrides. letter-spacing is unaffected.

Honest status: production currently contains 132 distinct serif size/weight combinations against these 6. Only exact matches have been migrated so far; most components still hand-write their type. Reach for the nearest token on new work rather than inventing a value.

Buttons

Components
Buttons are not pills. The pill treatment was retired in the light redesign. light-redesign.css rewrites .btn-gold and .btn-outline into plain text links with an animated underline — no background, no border, no radius, no arrow SVG. The demos below use the real production classes, so what you see here is exactly what ships.
Secondary / default CTA (.btn-outline)Most used · section footers on light bg
See all the ways to give View all activities
<a href="donate.html" class="btn-outline">See all the ways to give</a>
Serif, 15px, weight 400, sentence case (never uppercase). Colour --navy on light backgrounds. A 1px ::after underline sits at opacity 0.35; on hover it becomes a navy→gold→navy gradient shimmer. Do not add an arrow SVG — .btn-outline svg is display:none !important.
Gold CTA (.btn-gold)Dark sections only · hero, join
Support us Apply for membership
Identical geometry to .btn-outline, only the colour differs (--gold). Dark backgrounds only — gold text fails contrast on light. Inside .hero / .join / .cta-close, .btn-outline flips to rgba(255,255,255,0.88) and the hover shimmer becomes gold→white→gold.
Form Submit (.btn-contact)contact.html · full-width inline action
Hover: navy → navy-deep + shadow. Arrow: --gold-deep stroke. border-radius: --radius-md (8px) not a pill.

Form Inputs

Components
Input, Select, Textarea (.cf-group)contact.html
Bottom-stroke style: no box, no corners — only border-bottom defines the field. Default: 1.5px solid var(--rule) (#EFE8D7). Focus: 2px solid var(--gold-deep) (thicker line, no box-shadow ring). Background: transparent.
Floating label: each field has a <label> that overlaps the (invisible) placeholder until the field is focused or filled, then floats to a small uppercase label above (10.5px, letter-spacing:0.08em, matches .cri-label/.lcb-label convention). On focus it turns var(--gold-deep). Select is the exception: its label stays hidden (opacity:0) until a real option is chosen (.has-value, set by JS) — otherwise it would double up with the select's own placeholder option text.
